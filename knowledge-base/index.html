3. Nginx High-Concurrency Cache Rules for Newsrooms

To handle viral Discover spikes without crashing while ensuring Googlebot always receives un-cached news sitemaps, apply the following Nginx block: 

# Bypass fastcgi cache for news sitemaps and WebSub feeds
location ~* ^/(news-sitemap.*.xml|feed.*) {
    fastcgi_cache_bypass 1;
    fastcgi_no_cache 1;
    expires -1;
    add_header Cache-Control "no-store, no-cache, must-revalidate, max-age=0";
    try_files $uri $uri/ /index.php?$args;

# Microcache evergreen articles for 10 minutes to survive 50k concurrency

    add_header X-FastCGI-Cache $upstream_cache_status;
}

Frequently Asked Technical Questions: Knowledge Base

What is the optimal news article word count for Google News vs Google Discover?

For Google News breaking stories, concise dispatches of 400 to 700 words published rapidly yield the highest carousel CTR. For Google Discover, deeper analytical pieces of 1,200 to 2,000+ words with rich visual graphics (1200px+ width) generate higher dwell time and sustained multi-day algorithmic distribution.

Can changing a website's domain name preserve its Google News inclusion?

While Google allows 301 permanent redirects via the Change of Address tool, domain migrations frequently cause temporary loss of news crawl priority for 3 to 6 months. The Definitive News SEO Technical Compendium:
Architecture, Schema Standards, and Crawl Protocol Specifications

News search engine optimization operates under entirely different algorithmic paradigms than standard organic SEO. Traditional web search relies on cumulative link equity, keyword density, and historical domain authority. In contrast, news search engines—including Google News, Top Stories carousels, Google Discover, Bing News, and Yahoo Finance—prioritize real-time ingestion velocity, entity salience, structured journalistic schema, and publisher trust graph alignment. This compendium serves as the definitive reference for digital asset engineers and media investors.

1. Core Algorithmic Concepts & Architectural Terminology

WebSub (Formerly PubSubHubbub) Real-Time Notification Protocol

WebSub is an open, decentralized publish-subscribe protocol enabling websites to inform search engine crawlers of newly published articles instantly. Instead of Googlebot polling an RSS feed periodically every few hours, the publisher's server dispatches an HTTP POST webhook to a centralized hub (such as https://pubsubhubbub.appspot.com/ or https://superfeedr.com/hub/endpoint). The hub immediately pushes the update to subscriber crawlers, reducing discovery latency from hours to under 3 seconds.

Query Deserves Freshness (QDF) Heuristic Trigger

QDF is an algorithmic system patented by Google that detects sudden surges in query search volume across global search, Google News, and social media trends. When a term triggers QDF (such as an unexpected corporate merger, natural disaster, or earnings release), the standard organic SERP ranking algorithm is temporarily superseded. Google inserts a Top Stories carousel above traditional results, reserving top positions exclusively for domains with recognized news entity status.

IndexNow Protocol (Bing & Yandex Direct Ingestion)

IndexNow is an initiative created by Microsoft Bing and Yandex enabling publishers to inform search engines of URL additions, updates, or deletions directly via API. By submitting an HTTP JSON payload containing the updated URL and an authentication key hosted on the domain root, Bingbot indexes new news articles in under 3 seconds, eliminating crawl delays entirely across Windows 11 widgets and Edge Start feeds.

Entity Salience & Knowledge Graph Disambiguation

Modern news algorithms process content as interconnected entities rather than strings of keywords. Entity salience measures the relative prominence of a specific entity (person, company, geopolitical event) within an article. Articles that correctly reference recognized entities via Wikidata IDs and schema about and mentions properties achieve up to 3x higher placement in Google Discover and Top Stories.

3. XML News Sitemap Standards & Header Best Practices

Unlike standard XML sitemaps that catalogue years of evergreen URLs, a Google News XML sitemap must strictly adhere to Google's specialized news schema:

  • 48-Hour Lifecycle Limit: The sitemap must contain ONLY articles published within the preceding 48 hours. URLs older than 48 hours must be automatically evicted from the news sitemap to preserve crawl efficiency.
  • 1,000 URL Ceiling: Sitemaps should not exceed 1,000 URLs per file. High-frequency publishers should partition sitemaps into sub-indices (e.g., /news-sitemap-1.xml, /news-sitemap-2.xml).
  • Canonical Publisher Name Match: The <news:name> XML tag must exactly match the official publication name approved inside Google Publisher Center. Any string divergence can cause crawler ingestion rejection.
  • Server Cache Bypass: Configure Nginx/LiteSpeed cache rules to bypass caching on the news sitemap URL, ensuring Googlebot always receives real-time XML data upon polling.
